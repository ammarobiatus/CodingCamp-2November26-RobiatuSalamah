# To-Do Life Dashboard

A personal productivity dashboard built for the CodingCamp project.

## Features
- Digital clock and greeting based on the current time.
- Pomodoro Focus Timer with customizable duration.
- To-Do List with add, edit, complete, and delete features.
- Quick Links to favorite websites.
- Light and Dark Mode.
- Duplicate task prevention.

## Technologies
- HTML
- CSS
- Vanilla JavaScript
- Local Storage API

## Deployment
Published using GitHub Pages.
